### Day 1 Reflection

**One thing I understand more clearly about data now is:**  
Data is far more than the numbers I handle in my day-to-day data entry and review work. It comes in many forms, including text, images and audio, and it can be structured, semi-structured or unstructured. I also now understand how data analysts, data scientists and data engineers each play a different part in turning raw data into something valuable.

**One example of quantitative data and one example of qualitative data is:**  
Quantitative: the number of orders a restaurant receives each day, because it is a count that can be measured.  
Qualitative: a customer review written online, because it describes an experience in words rather than measuring it.

**One question I would like to answer using restaurant data is:**  
Which times of day and days of the week are busiest, so the restaurant can plan staffing and stock more effectively?

**One concept I want to practise further is:**  
Telling the difference between quantitative data and identifiers. A value made of digits, like an order ID, is not automatically quantitative, and I want to become confident spotting this quickly in real datasets.
